# JOS Compositor: bug reports

This is where JOS Compositor's bugs are reported. The program's code isn't
here: only the reports.

**To report a bug**, use **Help > Report a Bug** in JOS Compositor. It opens
the form here with your version, system and graphics card already filled in.
You can also open a new issue directly.

Please:
- Search first: someone may have reported it already (add what you know).
- Say what you did, what you saw, and what you expected (or what Nuke does).
- Drag screenshots or a short screen recording into the report.
- Attach a small project (zipped) when it helps us see the problem.

**This tracker is public.** Don't attach anything confidential (client
footage, unreleased work); a tiny example that shows the same problem is
best.
